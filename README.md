# Assaad Calories

تطبيق عربي لإدارة السعرات والوزن والماء، مبني كصفحة HTML ويمكن تغليفه كتطبيق Android باستخدام Capacitor.

## المزايا المضافة
- إعدادات كلمة مرور محلية (تعيين/تغيير/إلغاء). كلمة المرور لا تدخل في النسخة الاحتياطية.
- تصدير واستيراد نسخة JSON تشمل بيانات التطبيق وسجلاته وأصناف الطعام والوزن.
- متابعة الماء: كل ضغطة تضيف 250 مل، هدف يومي قابل للتعديل، تصفير تلقائي عند تغير التاريخ.
- قيم المدخول والمصروف والفائض وعدد العمليات.
- تقارير بفلاتر اليوم والشهر والسنة ومخطط زمني.
- معادلة الرصيد: الرصيد الأساسي + المدخول - المصروف - الفائض.
- يمكن تعديل الرصيد الأساسي من الإعدادات (الخيار 5).

## إنشاء APK محلياً
1. ثبّت Node.js LTS وAndroid Studio وAndroid SDK.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   ```bash
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. في Android Studio اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد APK عادةً داخل `android/app/build/outputs/apk/debug/`.

## رفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد كاملة (وليس ملف ZIP فقط).
3. بعد الرفع يمكن تنزيل المشروع أو استنساخه على الكمبيوتر ومتابعة تطويره.

## ملاحظات مهمة
- كلمة المرور قفل محلي بسيط وليست تشفيراً كاملاً لملفات التطبيق.
- النسخ الاحتياطي لا يتضمن كلمة المرور، وعند الاستيراد تبقى كلمة مرور الجهاز الحالي كما هي.
- بيانات التطبيق محفوظة محلياً في متصفح التطبيق؛ احرص على تصدير نسخة احتياطية قبل حذف التطبيق أو مسح بياناته.
- بعض الأيقونات والخطوط في النسخة الحالية تعتمد على CDN وتحتاج اتصال إنترنت لعرضها كاملة.
